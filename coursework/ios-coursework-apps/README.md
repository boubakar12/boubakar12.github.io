# UIKit App Development Coursework

Three iOS assignment snapshots are preserved in their supplied project
folders. These are coursework artifacts, not finished or currently tested
apps.

| Folder | Assignment | Reviewed status |
| --- | --- | --- |
| `A2-Profile/` | Profile | Includes fuller programmatic profile and edit-screen files at the folder root. The Xcode project references skeletal duplicate controllers under `A2/Controllers/`; the Save action only dismisses the editor and does not persist changes. |
| `A3-ChatDev/` | ChatDev | UIKit feed cells and controller scaffolding are present. The feed data source, post model, and network manager retain TODOs. |
| `A4-ChefOS/` | ChefOS | Xcode app shell with an empty generated view controller. |

The original assignment folders retain their Xcode project metadata and source
files. The archive README files list Swift 5, iOS 13+, and Xcode 12+ as the
original environment requirements. No current Xcode build was performed.
